# BAEK TO YOU

백현의 실제 영상에서 영어 표현을 발견하고 → 말해 보고 → 저장하고 → 반복하며 내 영어로 만드는 개인용 모바일 PWA.
HTML/CSS/JavaScript만 사용하고, 서버·유료 API 없이 GitHub Pages에서 무료로 동작합니다.

학습 흐름: **WATCH에서 표현 발견 → SAVED에 저장 → 반복 말하기 → APPLY로 내 문장 만들기 → 주기적으로 복습**

## 2026.11.05 (b) — 전화하기 · Before→After · 표현 복습 · 전체 디자인

### TALK (탭 이름 SPEAK → TALK)
1. **백현이랑 전화하기** (기존 통역 챌린지)
   - 그냥 전화하면 **지금 시간대에 어울리는 영상 자동 선택** (라이브 영상·최근에 안 한 영상 우선). ‘다른 영상 고르기’로 직접 선택 가능
   - 영상 제목·메모·대본 키워드로 장면을 추정해 **통화 콘셉트** 자동 설정 (예: 침대에 누워서 하는 통화, 밥 먹으면서 수다)
   - 첨부 사진 28장에 장소·옷차림·분위기·시간 태그를 달아 두고 **영상 장면과 가장 비슷한 사진**을 매칭 (시간대는 보조 점수). 영상 관리에서 사진 직접 지정 가능
   - 사진마다 **머리~턱 영역**을 저장 → 화면을 채우되 머리가 잘릴 것 같으면 그만큼만 축소하고 남는 곳은 블러 배경 (28장 × 4개 화면 크기 검사: 잘림 0)
   - 수신 화면: 사진 중심 풀스크린, Web Audio로 합성한 벨소리, 받기 버튼 모션. **받으면 사진은 사라지고 통화 중 다시 나오지 않음**
   - 영상 **처음부터 순서대로** 진행. 영어 3단어 미만·감탄사만 있는 발화만 제외
   - **끊김 수정**: ① 쉼표·연결어미(는데, 고, 서…)로 끝나는 발화는 다음 발화와 합침 ② 끝 시간을 다음 발화 직전까지(최대 +1초) 늘려 재생 ③ 구간 이동 직후 이전 위치 시간이 보고되면 바로 끝나던 문제 수정
   - 기록: **총 통화 시간** 중심 + 통화 횟수 · 가장 긴 통화 · 최근 통화 목록
2. **백현이랑 대화하기** (기존 질문 답하기): 미리 추천 없이 자유롭게 대답 → 더 자연스럽게 다듬기 → Before/After → **다듬은 문장으로 연습**
3. **백현이랑 오래 이야기하기** (기존 말하기 도전): 60초 → 내 답변(단어 수·지난 라운드 대비) → 작은 힌트(이유·예시·감정·경험·순서·계획… 아직 안 한 것 하나) → 다시 60초 반복

### 학습 화면
- **Before → After**: 빠진 말은 취소선, 바뀐/추가된 말은 핑크 하이라이트, 아래에 ‘바뀐 표현’ 목록 + 이유. 거의 다른 문장이면 “다른 표현으로 말했어요”
- 보고 말하기: 영어를 크게. 안 보고 말하기: **한국어를 위에** + **힌트 보기**(패턴·핵심 단어만 하나씩) + 정답 잠깐 보기

### SAVED
- 저장은 **개선된 추천 문장**으로 (원래 말한 문장은 before로 함께 보관)
- **표현 고르기**: 추천 문장에서 단어를 눌러 범위 선택 → 표현/단어로 저장, 문장 안에 하이라이트
- **표현·단어 탭**: 직접 추가·뜻 적기 → **새 문장 만들기 → 말하기 → 피드백 → 복습(익숙함 3단계)**, 만든 문장은 표현별로 쌓임
- 패턴은 **쉼표(,)로 여러 개** 등록, 한국어는 단어 단위 줄바꿈(keep-all)

### 디자인 (2차 수정)
- 그라데이션 배경 제거 → 흰 배경 + 얇은 선, 그림자 없음, 작은 글씨, 핑크는 포인트에만
- 폰트는 Pretendard 하나 (명조/세리프 제거), 버튼·카드 모서리 12~18px로 통일, 평평한 하단 탭바
- TALK: ‘백현이랑 전화하기’ 하나만 → 누르면 시간대에 맞춰 **랜덤 연결**, 어떤 영상인지는 연결 전까지 안 보여줌
- 전화 거는 화면: 사진이 블러에서 선명해지며 등장 → 빛이 한 번 지나감 → ‘잠들기 전 백현이랑’ 같은 한 줄 + 연결 중 점 애니메이션 + 끊기 버튼 파동 → 2.6~4초 뒤 백현이가 받으면 사진이 밝아지며 사라지고 영상통화 시작

### AI가 필요한 부분 — 실제 구현과 한계
| 기능 | 지금 방식 (무료) | 한계 |
|---|---|---|
| 영상 장면·콘셉트 분석 | 제목·메모·대본에서 키워드 규칙으로 추정 | 영상 화면 자체는 못 봄. 틀리면 영상 관리에서 장면 태그·사진 지정 |
| 사진 매칭 | 사진 태그는 첨부 사진을 보고 미리 달아 둔 값 | 새 사진을 넣으면 `js/scene.js`의 PHOTOS에 태그·머리 영역 추가 필요 |
| 원어민 표현으로 다듬기 | 내장 규칙(문법 + 한국식 영어 → 원어민 표현 약 40개) + LanguageTool 공개 서버(설정에서 끌 수 있음) | 문법·흔한 실수 위주. 문장 전체를 원어민처럼 의역하진 못함 → ‘Claude로 다듬기’(복사·붙여넣기, 무료) |
| 오래 이야기하기 힌트 | 내 답변에 이유/예시/감정 등이 있는지 규칙으로 확인 | 내용의 질은 판단 못 함 |
| 발음·억양 점수 | 제공 안 함 | 유료 음성 평가 엔진 필요 |
앱 안에서 바로 AI 피드백을 받으려면 유료 API + 키를 숨길 서버(예: Cloudflare Workers)가 필요해요.

## 이전: SPEAK — 백현이와 영상통화로 말하기 (2026.11.05)
TALK 탭을 SPEAK로 바꿈. 세 모드 모두 영상통화 화면이야. 백현이 얼굴(영상 클립 / 프로필 사진)이 화면 가득 나오고, 내가 말한 문장은 라이브 방송 채팅처럼 아래에서 올라와.
1. **통역 챌린지**: 백현이 클립 → 바로 영어로 → 원어민 추천 문장 → (선택) 추천 문장 연습 · 10문장
2. **백현이의 질문에 답하기**: 백현이 질문 클립(`type: "question"` 또는 ?로 끝나는 문장) → 30초~1분 대답 + 미션 패턴 → 같은 영상에서 백현이가 이어서 한 말 “백현이는 이렇게 말했어” → 더 자연스럽게 말하기 → 보고 말하기 → 안 보고 말하기 → 저장
3. **3번 말하기 도전**: 같은 질문 1분 → 40초 → 20초 (시간 되면 자동 종료) → 단어 수·속도 → 백현이 클립으로 마무리 → 연습
- **더 자연스럽게 말하기**: 규칙으로 다듬은 문장 + JSON의 `replies`(원어민 답변 예시) + Claude로 다듬기(요청문 복사 → 결과 붙여넣기) 중 골라서 바로 연습
- **오늘의 백현이**: 하루 첫 통화를 마치면 저장한 문장 중 하루 하나 클립
- 기록: 오늘 말한 시간 · 문장 수 · 연속 학습일
- 프로필 사진: `icons/baekhyun.jpg` (바꾸려면 같은 이름으로 교체)
- 질문 클립이 없으면 문장의 `question`(앱 질문)으로 진행하고 ‘앱 질문’으로 표시
- SETTINGS › 영상 관리: **JSON 전체 복사**, 교체 창에서 **현재 JSON 불러오기**

## 학습 간소화 (2026.11.05)
플래시카드 중심. 영어 문장을 여러 번 보여주지 않고, 직접 말하고 → 확인하고 → 응용하는 데 집중.

**WATCH 학습 순서** (버튼 하나로 다음 단계)
1. 영상 듣기 → 2. 영어로 말하기 → 3. 추천 문장 확인 → 4. 보고 말하기 → 5. 안 보고 말하기 → 6. 패턴으로 새 문장 말하기
- 플래시카드: 앞면 한국어, 탭하면 추천 문장(Natural) 하나, 다시 탭하면 한국어
- 확인 화면: 한국어 · 내 답변 · 추천 문장 세 줄만
- 마이크 인식 + 내 답변 직접 수정 유지, 말하기 시작하면 영상 자동 일시정지

**SAVED 복습**: 플래시카드 보고 말하기 → 추천 문장 확인 → 패턴으로 새 문장 → 익숙함 3단계 선택

**삭제한 것**: 영어 음성 듣기·천천히 듣기 등 모든 TTS, 쉐도잉, Easy/Advanced 선택, 단어 일치 점수·취소선 비교, 자막 아래 자동 영어 번역, 단계별 긴 설명, 힌트·예문 반복, 음성 설정
**데이터**: 영상·문장·SAVED·학습 기록 그대로. 문장은 `natural`만 사용 (natural이 비어 있는 예전 문장은 있는 영어 문장으로 대체). Easy/Advanced 값은 지우지 않고 보관만 함. 예전 단계 기록(WATCH·SHADOW·RETRY)은 새 단계(듣기·보고 말하기·안 보고 말하기)로 인정

- CHECK: Easy · Natural · Advanced를 세로로 나란히 비교, 레벨마다 듣기·저장 버튼
- 같은 문장인 레벨은 자동으로 한 칸에 합쳐 표시 (예: `Natural · Advanced`)
- **힌트 보기** 복구: 핵심 단어 → 문장 시작 → 핵심 패턴 → 첫 글자 빈칸, 4단계로 하나씩 공개
- **영상 자동 일시정지**: 마이크를 누르면 영상이 멈춤. 영상 ⏯ 버튼과 마이크 ■ 버튼은 따로 동작
- 오른쪽 위 ↗ 버튼: YouTube 앱에서 그 구간 바로 열기

### 3. 음성 인식·녹음
- **끝내기를 직접 눌러야만 종료**. 잠깐 멈춰도 끊기지 않고, 브라우저가 인식을 끊으면 자동으로 다시 이어서 들음
- 상태 표시: 마이크 준비 중 / 듣는 중 / 인식 중 / 정리하는 중 / 완료 / 오류 + 경과 시간
- 인식 결과는 항상 텍스트로 보여주고 직접 수정 가능, `이어 말하기` · `지우기`
- 음성 인식이 없는 브라우저: 녹음만 하는 모드로 자동 전환 (텍스트는 직접/키보드 받아쓰기)
- 마이크 권한·Siri/받아쓰기 꺼짐·네트워크 오류별 안내 문구
- 비교는 축약형(I'm=I am), 숫자(2=two), 대소문자, 문장부호를 무시하고 단어 단위로 관대하게
- 인식 언어 선택(en-US 기본), 인식 보정 단어 유지
- TALK도 수동 종료 + 보내기 전 확인·수정

### 4. 영어 음성(TTS)
- 기기 음성 중 **부드러운 남성 영어 음성** 우선 자동 선택 (Aaron, Evan, Nathan, Daniel, Arthur, Google UK English Male, Microsoft Andrew/Brian 등 기기에 있는 것)
- SETTINGS: 음성 선택(남성 / 기타 그룹), 속도, 톤, 미리 듣기, 현재 사용 중인 음성 표시
- 저장한 음성이 없는 기기에서는 추천 1순위로 자동 대체

### 5. APPLY — 6단계
Learn(패턴·의미·원문 예문) → Understand(같은 패턴 예문 3개) → Make It Yours(질문 + `I've been ______.` 힌트로 내 문장) → Speak(말하기·다시 말하기) → Feedback → Save
- 흔한 패턴 25개는 의미·예문·질문을 앱이 내장. 그 밖의 패턴은 JSON의 `patternKo / examples / question / frame` 사용
- Feedback (무료): 규칙 기반 문법·패턴·자연스러움 점검 → 다듬은 문장 제안 + 이유
  - 선택: `문법 정밀 검사` = 무료 LanguageTool 공개 서버 (누를 때만 문장 전송)
  - 선택: `Claude에 물어보기` = 피드백 요청문을 복사해 Claude 채팅에 붙여넣기 (추가 비용 없음)

### 6. SAVED
- WATCH에서 Easy/Natural/Advanced 중 골라서 저장, 한국어 뜻·영어·패턴·원본 영상(구간) 함께 저장, 중복 방지
- 분류: 오늘 복습 / 전체 / 연습 필요 / 익숙해진 / 내 문장
- 표현별 연습·듣기·원본 영상으로 이동·수정·삭제
- 반복 연습: **Recall → Speak → Check → Apply → Review**
- 학습 상태 3단계와 복습 간격
  - 다시 연습할래요 → 10분 뒤 (이번 세션 끝에 한 번 더)
  - 어느 정도 알아요 → 1 → 2 → 4 → 8일…
  - 완전히 익혔어요 → 4 → 10 → 25일…
- 오늘 복습 개수, 오늘 진행률, 익힌 표현 수, 4주 활동 기록

### 7. SETTINGS
- 영상별 **문장 전체 삭제** (영상·다른 영상은 유지, 확인창)
- **JSON 추가 / JSON 교체** 구분, 붙여넣기 또는 파일 선택
- 업로드 전 검사: 문법, 배열 형식, ko·영어 필수, 시간 형식 → 하나라도 틀리면 아무것도 바꾸지 않음
- 교체 시 SAVED 영향 미리 안내 (같은 한국어 문장이면 자동 재연결, 아니면 내용은 유지하고 연결만 해제)
- 위험한 작업(삭제·교체·복원·초기화) 직전 자동 스냅샷 → `직전 상태로 되돌리기`
- Claude용 JSON 프롬프트 개선: 레벨별 차이 규칙 + APPLY 필드

### 8. PWA 업데이트
- 서비스워커가 앱 파일을 항상 서버에 재검증(`cache: no-cache`) → **배포 때 캐시 버전을 손으로 바꿀 필요 없음**
- `sw.js`는 HTTP 캐시 없이 확인(`updateViaCache: 'none'`), 앱 실행·복귀 시 업데이트 확인
- 새 워커 활성화 시 **한 번만** 새로고침 (15초 내 재새로고침 차단)
- 옛 `baek-to-you-*` 캐시 자동 정리. localStorage·IndexedDB(학습 데이터)는 건드리지 않음
- 오프라인에서도 마지막으로 받은 버전으로 실행

## 브라우저·정책 때문에 제한되는 것과 대안

| 항목 | 상태 | 대안 |
|---|---|---|
| YouTube Premium 광고 없는 재생 (앱 안) | **보장 불가.** 임베드 플레이어는 브라우저의 YouTube 로그인 쿠키가 있어야 Premium이 적용되는데, iPhone Safari는 다른 사이트 쿠키를 기본 차단하고, 홈 화면 앱은 Safari와 쿠키가 분리됨 | 문장 화면 ↗ 버튼으로 **YouTube 앱에서 해당 구간 열기** (앱에서는 Premium 적용). 광고 차단·인증 우회는 구현하지 않음 |
| 완전한 수동 녹음 종료 | Web Speech API는 브라우저가 스스로 인식을 끊을 수 있음 | 끊기면 자동 재시작해 이어 붙임. 재시작 사이 아주 짧은 순간의 말은 빠질 수 있어 텍스트를 확인·수정하도록 함. 재시작이 막히면 `이어 말하기` |
| iPhone 음성 인식 | Siri/받아쓰기가 꺼져 있으면 동작 안 함. 홈 화면 앱 모드에서 인식이 안 되는 iOS 버전이 있음 | 설정 › 일반 › 키보드 › 받아쓰기 켜기. 안 되면 Safari 탭에서 열기 |
| 발음·억양 점수 | 전용 음성 평가 엔진(유료) 필요 → 제공 안 함 | 단어 비교, 말한 길이·끊김, 원어민↔내 녹음 번갈아 듣기 |
| 문법 피드백 | 규칙 기반이라 모든 오류를 잡지 못함 | LanguageTool(무료·외부 전송) 또는 Claude 채팅용 요청문 복사 |
| AI 자동 피드백(앱 안에서 바로) | 유료 API 키가 필요하고, 키를 브라우저에 넣으면 노출됨 → 별도 서버 필요 | 현재는 Claude 채팅에 붙여넣는 무료 방식 |
| 남성 TTS 음성 | 기기에 설치된 음성만 사용 가능. iPhone Safari는 일부 음성만 웹에 공개 | 남성 음성이 없으면 자동 대체 + SETTINGS에서 현재 음성 표시 |
| 백현 목소리 영어 | 실제 인물 목소리 복제는 하지 않음 | 분위기에 맞는 기기 남성 음성 |

외부 서버·유료 API가 필요한 기능은 없습니다. 선택 기능인 LanguageTool만 무료 외부 서버를 사용합니다.

## GitHub Pages 업로드 (kangseonwoo/baek-to-you → /baek-to-you/)

1. **먼저 기존 앱에서 SETTINGS › JSON 백업** 해 두기
2. 저장소 루트의 기존 파일을 이 폴더의 파일로 덮어쓰기
   - 새 파일 `js/apply.js`, `js/feedback.js`, `js/pwa.js`, `js/sync.js`, `js/merge.js`, `js/firebase-config.js`, `js/vendor/firebase.js`도 꼭 함께 올리기
   - `.nojekyll` 유지 (숨김 파일이라 업로드 시 빠지기 쉬움)
3. 경로는 전부 상대 경로라 `/baek-to-you/` 하위에서 그대로 동작
4. 배포 후 1~2분 기다렸다가 앱을 열면 자동으로 새 버전으로 한 번 새로고침됨
   - 처음 한 번은 기존(구버전) 서비스워커 때문에 두 번 열어야 반영될 수 있음
   - 그래도 이전 화면이면 SETTINGS › 이 기기·앱 정보 › `업데이트 확인`
5. 다음 배포부터는 **sw.js 버전을 고칠 필요 없음**. 앱 파일만 바꿔 올리면 됨

## 기존 데이터 유지 · 백업

- 저장 키(`baek-to-you:v1`)를 그대로 써서 기존 영상·문장·SAVED·학습 기록이 자동으로 이어짐. 새 필드(레벨, 학습 상태, 원본 영상 정보)는 처음 실행 때 자동으로 채워짐 (예전 ‘어려움’ 표시 → ‘연습 필요’)
- 기존 JSON 문장 형식 그대로 호환. 새 필드(`patternKo`, `examples`, `question`, `frame`)는 선택
- 백업: SETTINGS › JSON 백업 (영상·문장·SAVED·기록·설정. 녹음 파일 제외)
- 복원: SETTINGS › JSON 복원 › 합치기(추천) 또는 전체 바꾸기
- 실수로 지웠다면: SETTINGS › 직전 상태로 되돌리기 (가장 최근 1회)
- 데이터는 그 기기·그 브라우저에만 저장됨. Safari와 홈 화면 앱도 저장소가 다를 수 있으니 기기를 바꾸거나 앱을 지우기 전에 꼭 백업
